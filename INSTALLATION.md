# 📲 Installation Guide - Discipline Life Planner

## 🤖 Android Installation

### Method 1: Chrome Browser (Recommended) ⭐

**Steps:**
1. Open Chrome on your Android phone
2. Go to: `https://shruthipriya1120-ui.github.io/discipline-life-planner/`
3. Wait for the page to load completely (10-15 seconds)
4. You'll see a prompt: **"Install Discipline Planner?"**
5. Tap **"Install"** button
6. The app will be installed on your home screen
7. Tap the new icon to launch the app

**If prompt doesn't appear:**
- Tap the menu (⋮) at top-right corner
- Select **"Add to Home screen"**
- Confirm the app name
- Tap **"Add"**

### Method 2: Add to Home Screen (Alternative)

1. Open the app in Chrome
2. Tap the menu (⋮) at the top-right corner
3. Select **"Add to Home screen"**
4. A dialog will appear asking for app name
5. Keep it as "Discipline Planner" or customize
6. Tap **"Add"**
7. App will be added to your home screen

## 🍎 iPhone Installation

### Using Safari

1. Open Safari on your iPhone
2. Visit: `https://shruthipriya1120-ui.github.io/discipline-life-planner/`
3. Tap the Share button (square with arrow) at bottom
4. Scroll down and tap **"Add to Home Screen"**
5. Name the app: "Discipline Planner"
6. Tap **"Add"**
7. App icon will appear on your home screen

## 💻 Desktop Installation

### Windows 10/11 (Chrome)

1. Visit the app URL in Chrome
2. Click the install icon in the address bar (puzzle piece with plus)
3. Click **"Install"**
4. App will appear in Start Menu and desktop

### macOS (Chrome)

1. Visit the app URL in Chrome
2. Menu (⋮) → **"Create shortcut..."**
3. Check "Open as window"
4. Click **"Create"**

### Linux (Chrome)

1. Visit the app URL
2. Menu (⋮) → **"Create shortcut"**
3. Check "Open as window"
4. Shortcut will be created

## 🆘 Troubleshooting

### Problem: Install prompt not appearing

**Solution:**
- Make sure you're using **Chrome** browser
- Wait 15 seconds for app to fully load
- Try refreshing the page (Ctrl+Shift+R)
- Check your internet connection

### Problem: App crashes or won't load

**Solution:**
- Force stop the app
- Clear app data: Settings → Apps → Discipline Planner → Storage → Clear Data
- Reinstall by removing and re-adding to home screen

### Problem: Tasks not saving

**Solution:**
- Not using Incognito mode? (tasks won't save in private mode)
- Clear browser cache
- Check browser storage permissions

### Problem: Can't install on Android

**Solution:**
- Use Chrome browser (not Firefox or Safari)
- Connection must be HTTPS (which it is)
- Try "Add to Home screen" instead of install
- Clear browser cache and try again

## ❓ FAQs

**Q: Do I need to login?**  
A: No login required. All data is stored locally on your phone.

**Q: Is my data safe?**  
A: Yes! Data never leaves your device. No cloud storage, no tracking.

**Q: Can I use it offline?**  
A: Yes! After first load, it works completely offline.

**Q: Will my tasks be deleted?**  
A: Only if you manually clear browser data. Otherwise, data persists.

**Q: Can I access from multiple devices?**  
A: Yes, but each device has its own separate task list.
